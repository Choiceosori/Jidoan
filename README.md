# Jidoan — 질문이 넘치는 교수·학습 과정안 만들기

초등 차시 교수·학습 과정안(A4 세로 양식)을 단계별로 입력하고 **DOCX**로 내려받는 웹앱입니다.
서버 없이 `index.html` 파일 하나로 동작합니다.

## 기능
- 5단계 입력: 기본 정보 → 목표·의도·핵심 질문 → 교수·학습 활동(도입·전개·정리) → 평가(상·중·하) → 미리보기·출력
- 실시간 A4 세로 미리보기
- **DOCX 다운로드** (한글·MS워드에서 편집 가능)
- 🤖 **AI 초안 도우미**: 프롬프트를 복사해 챗GPT·Gemini·클로드 등에 붙여넣고, 응답(JSON)을 다시 붙여넣으면 초안이 채워짐 (API 키 불필요)
- 작성 점검: 도입 5분 이내, 전개 활동 2개 이내, 핵심 발문 2~3개, 과정중심평가(☑) 명시 등
- 브라우저 자동 저장, JSON 저장·불러오기

## 사용법
- 바로 쓰기: `index.html`을 내려받아 브라우저로 열기
- 웹에 올리기: 저장소 **Settings → Pages → Branch: `main` / root** 를 선택하면 `https://<사용자명>.github.io/Jidoan/` 에서 열 수 있음

## 입력 기호
| 기호 | 의미 |
|---|---|
| `▣` | 큰 활동(내용 요소) |
| `▪` | 세부 활동 |
| `-` | 하위 내용 |
| `【활동1】` | 전개 활동 번호 |
| `[모둠]` `[전체]` `[짝]` `[개인]` | 학습 형태 |
| `__낱말__` | 밑줄 |
| `□` `※` `☑` | 자료 · 유의점 · 평가 |

`examples/` 폴더에 예시안으로 만든 DOCX 출력물이 있습니다.
